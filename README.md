# 🛒 Дропшип-магазин

Сайт для дропшипинга на Cloudflare Pages: витрина с каталогом товаров, загрузка товаров из **XML-фида** (YML / Google Merchant / произвольный XML), интеграция с **Telegram**, **статистика** и **ИИ-аналитика** на Claude.

## Что внутри

| Раздел | Описание |
|--------|----------|
| **Витрина** (`/`) | Каталог с поиском, фильтром по категориям, сортировкой, корзиной и оформлением заказа |
| **Карточка товара** (`/product.html?id=…`) | Галерея, характеристики, похожие товары |
| **Админка** (`/admin.html`) | Вход по паролю, загрузка XML, управление товарами, статистика, ИИ-аналитика |
| **Telegram** | Заявки, заказы и отчёты ИИ автоматически падают в ваш чат/канал |
| **ИИ-аналитика** | Бесплатный ИИ разбирает магазин и даёт советы по дропшипингу |
| **Авто-подбор товара** | ИИ сам выбирает лучший товар, ставит наценку ×3, публикует «ХИТ» и шлёт отчёт в Telegram — можно по расписанию |
| **Конструктор набора** | Покупатель сам выбирает N из M товаров, цена пересчитывается вживую — растёт средний чек |
| **Telegram-бот** | Проводит покупателя по сборке набора кнопками и оформляет заказ |

Технологии: Cloudflare Pages + Pages Functions (API) + Cloudflare D1 (БД) + **Cloudflare Workers AI** (бесплатный ИИ). Внешних платных сервисов нет.

## Структура

```
index.html            витрина (каталог)
product.html          страница товара
admin.html            админ-панель
assets/css, assets/js статика (в т.ч. config.js — контакты магазина)
functions/api/…       API (Pages Functions)
functions/_lib/…      общие модули (БД, авторизация)
schema.sql            схема базы данных
wrangler.toml         конфиг Cloudflare
```

## Настройка (пошагово)

### 1. Создать базу данных D1
```bash
npx wrangler d1 create dropship-db
```
Скопируйте `database_id` из вывода и вставьте в `wrangler.toml` (поле `database_id`).

Примените схему:
```bash
npx wrangler d1 execute dropship-db --remote --file=./schema.sql
```

### 2. Задать секреты
В дашборде Cloudflare Pages → ваш проект → **Settings → Environment variables** (или через CLI `npx wrangler pages secret put <ИМЯ>`):

| Переменная | Обязательно | Что это |
|-----------|:----------:|---------|
| `ADMIN_PASSWORD` | ✅ | Пароль для входа в `/admin.html` |
| `AUTH_SECRET` | ✅ | Любая случайная строка 32+ символов (подпись сессии) |
| `BOT_TOKEN` | для Telegram | Токен бота от [@BotFather](https://t.me/BotFather) |
| `CHAT_ID` | для Telegram | ID чата/канала, куда слать заказы и отчёты ИИ |
| `CRON_SECRET` | для авто-подбора | Любая случайная строка — защита авто-запуска по расписанию |
| `TG_WEBHOOK_SECRET` | для бота | Любая случайная строка — защита вебхука Telegram-бота |
| `MARKUP` | нет | Наценка авто-подбора, по умолчанию `3` (×3) |
| `GEMINI_API_KEY` | нет | Бесплатный ключ [Google Gemini](https://aistudio.google.com/apikey). Если задан — ИИ использует Gemini вместо Workers AI |

> **Как узнать CHAT_ID:** напишите боту, затем откройте `https://api.telegram.org/bot<BOT_TOKEN>/getUpdates` — id чата будет в ответе.

### 3. Привязать D1 и Workers AI к Pages
В дашборде проекта: **Settings → Functions**
- **D1 database bindings** → добавьте binding `DB` → `dropship-db`
- **AI bindings** → добавьте binding `AI` (это включает бесплатный Cloudflare Workers AI)

(Либо всё подхватится из `wrangler.toml` при деплое через `wrangler pages deploy`.)

### 4. Настроить контакты магазина
Отредактируйте `assets/js/config.js` — название, ссылку на Telegram-менеджера, телефон, валюту.

### 5. Задеплоить
Проще всего — подключить репозиторий к Cloudflare Pages (авто-деплой при push). Либо вручную:
```bash
npx wrangler pages deploy .
```

## Как загрузить товары

1. Откройте `/admin.html`, войдите по паролю.
2. Вкладка **📥 Импорт** → перетащите XML-файл поставщика.
3. Файл распознаётся прямо в браузере, показывается превью.
4. Выберите режим (*дополнить* или *заменить каталог*) → **Загрузить в каталог**.

Поддерживаемые форматы фида:
- **YML** (Yandex Market Language) — большинство дропшип-поставщиков, Prom.ua и т.п.
- **Google Merchant** (RSS с тегами `g:`)
- Произвольный XML с тегами `<offer>`, `<item>` или `<product>`

Распознаются: название, цена, старая цена, валюта, категория, бренд, изображения (несколько), наличие, характеристики (`<param>`), ссылка.

## 🤖 ИИ и автоматика

**ИИ бесплатный.** По умолчанию используется **Cloudflare Workers AI** (модель Llama 3.3 70B) — работает прямо на хостинге, без внешнего ключа, с бесплатным дневным лимитом. Если хотите чуть более сильную аналитику — добавьте бесплатный `GEMINI_API_KEY`, и код автоматически переключится на Google Gemini.

**Что умеет ИИ:**
- **Разбор магазина** (вкладка «ИИ-аналитика» → «Проанализировать») — советы по товарам, ценам, конверсии, продвижению.
- **Авто-подбор товара** («Найти и внедрить») — ИИ выбирает из каталога лучший товар, ставит цену = закупка × наценка (по умолчанию ×3), делает его «ХИТом» на витрине и присылает в Telegram отчёт: что за товар, расчёт наценки и прибыли, почему зайдёт, готовый пост.

### Автоматический запуск по расписанию
Каждый день сам подбирать товар и слать отчёт в Telegram:

1. Задайте секрет `CRON_SECRET` на сайте (см. таблицу выше).
2. Разверните мини-воркер-планировщик:
   ```bash
   cd automation-worker
   # укажите адрес сайта в wrangler.toml (SITE_URL) и расписание (crons)
   npx wrangler deploy
   npx wrangler secret put CRON_SECRET   # то же значение, что и на сайте
   ```
   Готово — воркер по расписанию будет запускать подбор.

   **Без кода:** можно вместо воркера настроить бесплатный [cron-job.org] — он по расписанию делает `POST` на `https://ВАШ-САЙТ/api/admin/auto-pick` с заголовком `X-Cron-Secret: <ваш CRON_SECRET>`.

### Важно про «тренды из интернета»
Бесплатный ИИ **не заходит в интернет** и не знает тренды в реальном времени. Поэтому авто-подбор работает по **вашему каталогу** — по товарам, которые вы загрузили из XML-фида поставщика (там и есть новинки), и по статистике магазина. Чтобы у ИИ всегда были свежие товары для выбора — регулярно обновляйте фид на вкладке «Импорт».

## 🎁 Конструктор набора (выбери N из M)

Фишка, которую сложно скопировать на шаблонном магазине: покупатель сам собирает комплект, цена считается вживую.

**Создать набор:** админка → вкладка **🎁 Наборы**:
1. Название и описание.
2. «Сколько выбрать» (N) и режим цены:
   - **Фиксированная за N** — любые N позиций за одну цену («3 по цене 2»);
   - **Скидка %** — процент на сумму выбранных;
   - **Сумма выбранных** — просто сумма.
3. Добавьте товары-варианты (поиск по каталогу).
4. Сохраните — набор появится на главной («🎁 Собери свой набор») и по ссылке `/bundle.html?id=…`.

На витрине покупатель отмечает N карточек, цена пересчитывается, набор добавляется в корзину одной позицией.

## 🤖 Telegram-бот сборки набора

Бот проводит покупателя по сборке набора кнопками и оформляет заказ прямо в чате.

**Подключение (1 раз):**
1. Создайте бота у [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN` → задайте секретом на сайте.
2. Задайте `TG_WEBHOOK_SECRET` (любая строка) и `CHAT_ID` (куда слать заказы).
3. Админка → вкладка **🎁 Наборы** → кнопка **«Подключить бота»** (ставит вебхук на ваш сайт).

**Как работает:** покупатель пишет боту `/start` → выбирает набор → отмечает позиции кнопками (✅), видит сумму → «Оформить» → отправляет номер телефона → заказ создаётся в базе и падает вам в Telegram.

## Локальная разработка
```bash
npx wrangler pages dev . --d1 DB=dropship-db --ai AI
# схема для локальной БД:
npx wrangler d1 execute dropship-db --local --file=./schema.sql
```

## Безопасность
- Админка защищена паролем (`ADMIN_PASSWORD`), сессия — подписанная HttpOnly-кука.
- Токены и ключи хранятся только в секретах Cloudflare, в коде их нет.
- XML парсится в браузере, на сервер уходит уже нормализованный JSON.
